# Release notes — 2026-07-04

## English

### Full list (to share directly)

**New**

- **Edit a text file** straight from Dropbox (or any other storage): pick the file once in Settings → File, or use "Open with…" from the Dropbox app. The `F2` key opens it, and changes are saved automatically — while typing pauses, and when leaving the editor. A read-only file opens read-only.
- **Text-to-speech settings**: choose your own speak key, add a separate "speak everything" key, adjust speech rate (25–120%) and pitch, or turn text-to-speech off entirely.
- **Speak the sentence under the cursor**: move the cursor to any line and press the speak key to hear exactly that sentence. A new line now also ends a sentence. With the cursor at the end, it reads the last sentence as before.
- **Yes/no interrupts speech**: pressing the yes or no key stops ongoing speech first, so the answer is always clearly heard.

**Fixed**

- Crash when pressing the speak key while the text was empty.
- Loaded text and abbreviation expansions could accidentally trigger command keys and lose characters; the cursor also no longer jumps when using a command key mid-text.
- The settings button sat too deep in the corner, inside the system-bar swipe area.

**Improved**

- The settings screen has a modern look, follows the system dark mode, and now refuses to assign one key to two different commands (it tells you which command already uses the key).

**Removed**

- The old "download a .txt file from a URL" viewer has been replaced by the new file editing. If you used it, pick your file once via Settings → File.

### Play Store release notes (short, ≤500 characters)

## Nederlands

### Volledige lijst (om direct te delen)

**Nieuw**

- **Bewerk een tekstbestand** rechtstreeks uit Dropbox (of andere opslag): kies het bestand eenmalig via Instellingen → Bestand, of gebruik "Openen met…" vanuit de Dropbox-app. De `F2`-toets opent het, en wijzigingen worden automatisch opgeslagen — tijdens typpauzes en bij het verlaten van de editor. Een alleen-lezen bestand opent als alleen-lezen.
- **Tekst-naar-spraak instellingen**: kies je eigen voorleestoets, voeg een aparte "alles voorlezen"-toets toe, pas spreeksnelheid (25–120%) en toonhoogte aan, of zet tekst-naar-spraak helemaal uit.
- **De zin onder de cursor voorlezen**: zet de cursor op een regel en druk op de voorleestoets om precies die zin te horen. Een nieuwe regel telt nu ook als zinseinde. Met de cursor aan het einde wordt zoals voorheen de laatste zin voorgelezen.
- **Ja/nee onderbreekt spraak**: de ja- of nee-toets stopt eerst het voorlezen, zodat het antwoord altijd duidelijk te horen is.

**Opgelost**

- Crash bij het indrukken van de voorleestoets terwijl de tekst leeg was.
- Geladen tekst en afkorting-uitbreidingen konden per ongeluk commandotoetsen activeren en tekens laten verdwijnen; de cursor springt ook niet meer weg bij een commandotoets midden in de tekst.
- De instellingenknop zat te diep in de hoek, in het veeggebied van de systeembalk.

**Verbeterd**

- Het instellingenscherm heeft een moderne uitstraling, volgt de donkere modus van het systeem, en weigert nu één toets aan twee commando's toe te wijzen (je ziet welk commando de toets al gebruikt).

**Verwijderd**

- De oude "download een .txt-bestand van een URL"-weergave is vervangen door het nieuwe bestandsbewerken. Gebruikte je die functie, kies dan eenmalig je bestand via Instellingen → Bestand.
