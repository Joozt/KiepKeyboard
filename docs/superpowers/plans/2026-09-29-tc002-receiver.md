# Ulanzi TC002 KiepDisplay Receiver Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Ulanzi TC002 pixel clock into a KiepDisplay BLE receiver (same protocol as the TC001 and the Android "KiepKeyboard Display"), with one row of tall text, smooth scrolling, a Docker build, and a laptop-driven verification loop.

**Architecture:** A FlyThings `libzkgui.so` (C++17) loaded by the stock `zkgui` loader. Pure logic (`Presenter`: protocol → framebuffer, host-tested) is separated from device glue (SPI panel, MCU UART, evdev knob, audio, BLE bring-up, BlueZ GATT server). A dedicated render thread ticks at a fixed 30 ms cadence. Debug builds tap every frame into a ring file that host tools render.

**Tech Stack:** C++17 / C, CMake + Ninja in Docker (Arm GNU 8.3-2019.03 cross toolchain, FlyThings Z21 SDK headers), BlueZ shared GATT library (prebuilt `libgatt-server.a`), Python 3 host tools (`bleak`, Pillow, `adb`).

**Spec:** `docs/proposals/tc002-receiver.md` (protocol: `docs/proposals/external-display.md`; TC001 reference: `UlanziReceiver/src/main.cpp`).

## Global Constraints

- Protocol byte-identical to TC001: service `b1e60001-8f2a-4d0c-9e4b-5c3d2a1f0e9d`, Text `b1e60002-…`, Attention `b1e60003-…`; Text value = 1 type byte (`M`/`W`/`L`) + UTF-8; Attention = `[effect, count]`, effect 1 attention, 2 yes, 3 no. Device name `KiepDisplay`. No app changes.
- **No Wi-Fi network, ever.** No `wpa_supplicant`, no SSID, no DHCP, no AP mode. Only kernel modules needed for Bluetooth firmware may be loaded.
- Panel 52×16; frame to panel = 3072 bytes (16 rows × (52×3 RGB + 36 zero bytes)); ≥ 15 ms between frames; GPIO35 latch pulse required.
- Render tick `TICK_MS = 30`, one pixel per tick; heartbeat pixel (51,0) color `#33B5E5` (51,181,229); attention white 120 ms on / 80 ms off × count; yes `(0,152,0)`, no `(190,0,0)`, 800 ms; idle clear 10 min; brightness levels `{16,48,96,160,255}`.
- Font: caps 12 px (rows 1–12), descenders rows 13–15, row 0 blank; generated from DejaVu Sans Bold; ASCII 32–126 + Latin-1 letters.
- App entry must set `sys.zkapp.state=running` first (15 s watchdog). App never exits on bring-up failure.
- Build only in Docker; host (Windows) runs only `adb` + Python tools. Build outputs and SDK cache live in Docker volumes, not in the Dropbox-synced tree (Dropbox dehydrates build outputs). Device bundle copied to `UlanziTC002Receiver/out/` (gitignored).
- Licenses: our code MIT (repo license). BlueZ shared lib LGPL-2.1 (notice file). Demo code from `UlanziTechnology/Ulanzi-U-Clock-TC002` is GPL-3: **never copy it**, only its prebuilt BlueZ artifacts (BlueZ's own license).
- Commits: one per task, author Joozt (local config already set), **no `Co-Authored-By` trailer**, never push.
- Spikes are go/no-go gates: Task 3 (toolchain), Task 4 (BLE without network, hard gate), Task 5 (loader). No feature work past a failed gate.

## Review Focus

1. **Text frame longer than one ATT packet (>244 bytes).** Android splits into prepared writes; the receiver must show the complete text once, never a truncated or doubled one. Pinned by the chunk assembler in Task 6 and the Task 9 fixture `m_long_write` (300-byte message sent from the laptop).
2. **Unsupported codepoint (emoji, CJK) or invalid UTF-8 byte.** Must render `?` and never crash or desync following glyphs. Pinned in Task 2 test `test_unknown_codepoint_and_bad_utf8`.
3. **Frames arriving faster than the tick (character mode, fast typist).** Only the newest text may render; no queue growth, no lag. Pinned in Task 2 `test_rapid_updates_show_latest_only` and Task 6 settle logic.
4. **BLE disconnect during a scroll or flash.** Panel must clear immediately and advertising restart; the flash state must not survive into the next connection. Pinned in Task 2 `test_disconnect_clears_text_and_flash`, Task 9 fixture `disconnect_clear`.
5. **Power loss / crash loop.** Three crashes revert to stock; every bring-up failure logs and continues. Pinned in Task 3 (all device subsystems wrapped, `start()` never throws) and Task 6 review checklist.

- [ ] **Step 4: fetch-sdk.py**

```python
#!/usr/bin/env python3
"""Fetch FlyThings Z21 SDK packages and BlueZ artifacts into .cache/sdk (pinned)."""
import hashlib, json, pathlib, sys, urllib.request, zipfile
ROOT = pathlib.Path(__file__).resolve().parents[1]
LOCK = ROOT / "tools/sdk-lock.json"
CACHE = ROOT / ".cache/sdk"

def sha256(p): return hashlib.sha256(p.read_bytes()).hexdigest()

def fetch(url, dest):
    dest.parent.mkdir(parents=True, exist_ok=True)
    if not dest.exists():
        print("fetch", url); urllib.request.urlretrieve(url, dest)
    return dest

def main():
    lock = json.loads(LOCK.read_text()); changed = False
    for p in lock["packages"]:
        z = fetch(f'{lock["sdk_base"]}/{p["name"]}/{p["version"]}.zip', CACHE / f'{p["name"]}-{p["version"]}.zip')
        h = sha256(z)
        if p["sha256"] is None: p["sha256"] = h; changed = True; print("pinned", p["name"], h)
        elif p["sha256"] != h: sys.exit(f'sha256 mismatch for {z}: {h}')
        out = CACHE / p["name"]
        if not out.exists(): zipfile.ZipFile(z).extractall(out)
    b = lock["bluez"]; base = b["base"].format(commit=b["commit"])
    for h in b["headers"]: fetch(f"{base}/include/ble/{h}", CACHE / "bluez/include/ble" / h)
    lib = fetch(f"{base}/lib/libgatt-server.a", CACHE / "bluez/lib/libgatt-server.a")
    if sha256(lib) != b["lib_sha256"]: sys.exit("libgatt-server.a sha256 mismatch")
    if changed: LOCK.write_text(json.dumps(lock, indent=2) + "\n")
    print("sdk ok:", CACHE)

if __name__ == "__main__": main()
```

- [ ] **Step 1: Write gen-font.py**

```python
#!/usr/bin/env python3
"""Render DejaVu Sans Bold to a 1-bit bitmap font with 12 px caps in a 16-row cell -> src/Font.h.
Row 0 blank, caps rows 1..12, descenders rows 13..15. Run inside the build container."""
import pathlib, sys
from PIL import Image, ImageDraw, ImageFont
TTF = "/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf"
OUT = pathlib.Path(__file__).resolve().parents[1] / "src/Font.h"
CELL_H, CAP_H, BASELINE = 16, 12, 13          # baseline y: caps occupy rows 1..12
CHARS = [chr(c) for c in range(32, 127)] + list("¡¿ÀÁÂÃÄÅÆÇÈÉÊËÌÍÎÏÑÒÓÔÕÖØÙÚÛÜÝßàáâãäåæçèéêëìíîïñòóôõöøùúûüýÿ€")

def cap_height(font):
    img = Image.new("L", (64, 64), 0); ImageDraw.Draw(img).text((8, 40), "H", font=font, fill=255, anchor="ls")
    rows = [y for y in range(64) if any(img.getpixel((x, y)) > 127 for x in range(64))]
    return rows[-1] - rows[0] + 1

def pick_size():
    for size in range(10, 30):
        if cap_height(ImageFont.truetype(TTF, size)) >= CAP_H: return size
    sys.exit("no size gives 12 px caps")

def render(font, ch):
    adv = max(1, round(font.getlength(ch)))
    img = Image.new("L", (adv + 8, CELL_H), 0)
    ImageDraw.Draw(img).text((0, BASELINE), ch, font=font, fill=255, anchor="ls")
    cols = [x for x in range(img.width) if any(img.getpixel((x, y)) > 127 for y in range(CELL_H))]
    width = max(adv, (cols[-1] + 1) if cols else 0)
    rows = [sum(1 << x for x in range(min(width, 16)) if img.getpixel((x, y)) > 127) for y in range(CELL_H)]
    return min(width, 16), rows

def main():
    font = ImageFont.truetype(TTF, pick_size())
    assert cap_height(font) == CAP_H, cap_height(font)
    glyphs = sorted((ord(c),) + render(font, c) for c in CHARS)
    lines = ["// Generated by tools/gen-font.py from DejaVu Sans Bold. Do not edit.",
             "#pragma once", "#include <stdint.h>", "#define KIEP_FONT_HEIGHT 16", "#define KIEP_GLYPH_GAP 1",
             "struct KiepGlyph { uint32_t codepoint; uint8_t width; uint16_t rows[16]; };",
             "static const KiepGlyph KIEP_GLYPHS[] = {"]
    for cp, w, rows in glyphs:
        lines.append(f"  {{{cp}, {w}, {{{', '.join(str(r) for r in rows)}}}}}, // {chr(cp)!r}")
    lines += ["};", f"static const int KIEP_GLYPH_COUNT = {len(glyphs)};", ""]
    text = "\n".join(lines)
    if "--check" in sys.argv:
        sys.exit(0 if OUT.read_text() == text else "Font.h out of date: run tools/gen-font.py")
    OUT.write_text(text); print("wrote", OUT, len(glyphs), "glyphs, size", font.size)

if __name__ == "__main__": main()
```

Layout rules (spec §2): `M`/`W` centered when `width <= W`; else scroll in from `x = W`, one px per tick, until `x == W - width` (tail held, right edge on column 51). A `W` frame that extends the current text (old text non-empty and a prefix of the new) keeps `x` if scrolling; if held and now overflowing, it resumes scrolling from the current `x`. `L`: `x = 0` when fitting, else `x = W - width`; never scrolls. `\n`/`\r` → space. Unknown codepoint / malformed UTF-8 → `?`. Flashes replace the text: attention = white `ATTENTION_ON_MS` / black `ATTENTION_OFF_MS` × count, one beep per onset; yes/no = solid `ANSWER_MS`. Heartbeat (51,0) `#33B5E5`, solid when connected, toggling every 500 ms when not, `(200,0,0)` when battery low, drawn last. Brightness multiplies all channels by `BRIGHTNESS_LEVELS[level]/255`. Idle: text cleared once `now - lastTextMs > idleMs`.

```cpp
#include "Presenter.h"
#include "Font.h"
#include <algorithm>
#include <cstring>
namespace kiep {

void Frame::clear() { std::memset(rgb, 0, sizeof rgb); }
void Frame::set(int x, int y, uint8_t r, uint8_t g, uint8_t b) {
  if (x < 0 || x >= W || y < 0 || y >= H) return;
  uint8_t* p = &rgb[(y * W + x) * 3]; p[0] = r; p[1] = g; p[2] = b;
}
bool Frame::lit(int x, int y) const { const uint8_t* p = &rgb[(y * W + x) * 3]; return (p[0] | p[1] | p[2]) != 0; }

static const KiepGlyph* findGlyph(uint32_t cp) {
  int lo = 0, hi = KIEP_GLYPH_COUNT - 1;
  while (lo <= hi) {
    int mid = (lo + hi) / 2; uint32_t c = KIEP_GLYPHS[mid].codepoint;
    if (c == cp) return &KIEP_GLYPHS[mid];
    if (c < cp) lo = mid + 1; else hi = mid - 1;
  }
  return nullptr;
}
static const KiepGlyph* glyph(uint32_t cp) { const KiepGlyph* g = findGlyph(cp); return g ? g : findGlyph('?'); }

std::vector<uint32_t> Presenter::decode(const std::string& s) {
  std::vector<uint32_t> out; size_t i = 0;
  while (i < s.size()) {
    unsigned char c = s[i]; uint32_t cp; int n;
    if (c < 0x80) { cp = c; n = 1; }
    else if ((c & 0xE0) == 0xC0) { cp = c & 0x1F; n = 2; }
    else if ((c & 0xF0) == 0xE0) { cp = c & 0x0F; n = 3; }
    else if ((c & 0xF8) == 0xF0) { cp = c & 0x07; n = 4; }
    else { out.push_back('?'); i++; continue; }
    if (i + n > s.size()) { out.push_back('?'); break; }
    bool ok = true;
    for (int k = 1; k < n; k++) {
      unsigned char cc = s[i + k];
      if ((cc & 0xC0) != 0x80) { ok = false; break; }
      cp = (cp << 6) | (cc & 0x3F);
    }
    if (!ok) { out.push_back('?'); i++; continue; }   // resync on the next byte
    if (cp == '\n' || cp == '\r') cp = ' ';
    out.push_back(findGlyph(cp) ? cp : '?');
    i += n;
  }
  return out;
}

static int widthOf(const std::vector<uint32_t>& cps) {
  if (cps.empty()) return 0;
  int w = 0; for (uint32_t cp : cps) w += glyph(cp)->width + KIEP_GLYPH_GAP;
  return w - KIEP_GLYPH_GAP;
}
int Presenter::textWidth(const std::string& utf8) { return widthOf(decode(utf8)); }

void Presenter::onText(char type, const std::string& utf8, int64_t now) {
  bool extension = type == 'W' && !text_.empty() && utf8.size() > text_.size() && utf8.compare(0, text_.size(), text_) == 0;
  text_ = utf8; type_ = type; cps_ = decode(utf8); width_ = widthOf(cps_); lastTextMs_ = now;
  if (type != 'L') lastMessage_ = utf8;
  layout(extension);
}

void Presenter::layout(bool extension) {
  bool overflow = width_ > W;
  if (type_ == 'L') { scrolling_ = false; x_ = overflow ? W - width_ : 0; return; }
  if (extension) {
    if (scrolling_) return;                        // running scroll continues into the appended words
    if (overflow) { scrolling_ = true; return; }   // held text stopped fitting: resume from the current x_
    x_ = (W - width_) / 2; return;
  }
  if (overflow) { scrolling_ = true; x_ = W; } else { scrolling_ = false; x_ = (W - width_) / 2; }
}

void Presenter::clearText() { text_.clear(); cps_.clear(); width_ = 0; scrolling_ = false; }

void Presenter::onAttention(uint8_t effect, uint8_t count, int64_t now) {
  flash_ = effect == 1 ? ATTENTION : effect == 2 ? YES : effect == 3 ? NO : NONE;
  flashCount_ = std::clamp<int>(count, 1, 5); flashStartMs_ = now; beepedOnsets_ = 0; attentionOn_ = false;
}
void Presenter::onConnected(bool c, int64_t now) {
  connected_ = c; lastHeartbeatMs_ = now;
  if (!c) { clearText(); flash_ = NONE; }
}
void Presenter::replay(int64_t now) { if (!lastMessage_.empty()) onText('M', lastMessage_, now); }
void Presenter::setBrightnessLevel(int level) { brightness_ = std::clamp(level, 0, 4); }
int Presenter::takeBeeps() { int b = beeps_; beeps_ = 0; return b; }

bool Presenter::tick(int64_t now, Frame& out) {
  if (!text_.empty() && now - lastTextMs_ > idleMs_) clearText();
  if (scrolling_) { x_--; if (x_ <= W - width_) { x_ = W - width_; scrolling_ = false; } }
  if (!connected_ && now - lastHeartbeatMs_ >= HEARTBEAT_TOGGLE_MS) { lastHeartbeatMs_ = now; heartbeatOn_ = !heartbeatOn_; }
  if (flash_ == ATTENTION) {
    int64_t el = now - flashStartMs_, period = ATTENTION_ON_MS + ATTENTION_OFF_MS; int idx = int(el / period);
    if (idx >= flashCount_) { flash_ = NONE; attentionOn_ = false; }
    else {
      attentionOn_ = el % period < ATTENTION_ON_MS;
      if (attentionOn_ && idx + 1 > beepedOnsets_) { beepedOnsets_ = idx + 1; beeps_++; }
    }
  } else if (flash_ != NONE && now - flashStartMs_ >= ANSWER_MS) flash_ = NONE;
  render(out);
  bool changed = !haveLast_ || std::memcmp(out.rgb, last_.rgb, sizeof out.rgb) != 0;
  last_ = out; haveLast_ = true;
  return changed;
}

void Presenter::render(Frame& f) const {
  f.clear();
  if (flash_ != NONE) {
    uint8_t r = 0, g = 0, b = 0; bool paint = true;
    if (flash_ == ATTENTION) { paint = attentionOn_; r = g = b = 255; }
    else if (flash_ == YES) g = 152;
    else r = 190;
    if (paint) for (int y = 0; y < H; y++) for (int x = 0; x < W; x++) f.set(x, y, r, g, b);
  } else {
    int x = x_;
    for (uint32_t cp : cps_) {
      const KiepGlyph* gl = glyph(cp);
      if (x + gl->width > 0 && x < W)
        for (int y = 0; y < H; y++) for (int cx = 0; cx < gl->width; cx++)
          if (gl->rows[y] & (1u << cx)) f.set(x + cx, y, 255, 255, 255);
      x += gl->width + KIEP_GLYPH_GAP;
    }
  }
  if (connected_ || heartbeatOn_) { if (batteryLow_) f.set(W - 1, 0, 200, 0, 0); else f.set(W - 1, 0, 51, 181, 229); }
  uint8_t s = BRIGHTNESS_LEVELS[brightness_];
  for (uint8_t& v : f.rgb) v = uint8_t(v * s / 255);
}
}
```

```cpp
  int ex = ::open("/sys/class/gpio/export", O_WRONLY);
  if (ex >= 0) { ::write(ex, "35", 2); ::close(ex); }   // EBUSY when already exported is fine
  int dir = ::open("/sys/class/gpio/gpio35/direction", O_WRONLY);
  if (dir >= 0) { ::write(dir, "out", 3); ::close(dir); }
  gpio_ = ::open("/sys/class/gpio/gpio35/value", O_WRONLY);
  if (gpio_ < 0) { KLOGW("panel: gpio35 value failed: %s", strerror(errno)); return false; }
  writeGpio(1);
  KLOG("panel: open");
  return true;
}
bool Panel::writeGpio(int v) { const char c = v ? '1' : '0'; return pwrite(gpio_, &c, 1, 0) == 1; }
void Panel::send(const Frame& f) {
  if (spi_ < 0 || gpio_ < 0) return;
  uint8_t buf[H * ROW_BYTES]; std::memset(buf, 0, sizeof buf);
  for (int y = 0; y < H; y++) std::memcpy(&buf[y * ROW_BYTES], &f.rgb[y * W * 3], W * 3);
  writeGpio(0); usleep(1000);
  ::write(spi_, buf, sizeof buf);
  usleep(1000); writeGpio(1);
}
void Panel::close() {
  Frame black; black.clear(); send(black); usleep(20000); send(black);
  if (spi_ >= 0) ::close(spi_); if (gpio_ >= 0) ::close(gpio_); spi_ = gpio_ = -1;
}
```

```c
#include "KiepGatt.h"
#include <pthread.h>
#include <stdio.h>
#include <string.h>
#include <sys/socket.h>
#include <unistd.h>
#include <android/log.h>
#include "ble/bluetooth.h"
#include "ble/hci.h"

#include "ble/gatt-db.h"

#define LOG(...) __android_log_print(ANDROID_LOG_INFO, "kiep", __VA_ARGS__)
#define ATT_CID 4
#define SERVICE_UUID   "b1e60001-8f2a-4d0c-9e4b-5c3d2a1f0e9d"
#define TEXT_UUID      "b1e60002-8f2a-4d0c-9e4b-5c3d2a1f0e9d"
#define ATTENTION_UUID "b1e60003-8f2a-4d0c-9e4b-5c3d2a1f0e9d"

static kiep_gatt_callbacks g_cb; static struct gatt_db* g_db; static int g_hci = -1, g_listen = -1;
static struct bt_att* g_att; static struct bt_gatt_server* g_server; static pthread_t g_thread;

static void advertise(int on) {
  if (g_hci < 0) return;
  if (on) {
    le_set_advertising_parameters_cp p; memset(&p, 0, sizeof p);
    p.min_interval = htobs(0x00A0); p.max_interval = htobs(0x00F0); p.advtype = 0x00; /* ADV_IND */
    p.own_bdaddr_type = LE_PUBLIC_ADDRESS; p.chan_map = 7;
    hci_send_cmd(g_hci, OGF_LE_CTL, OCF_LE_SET_ADVERTISING_PARAMETERS, LE_SET_ADVERTISING_PARAMETERS_CP_SIZE, &p);
    le_set_advertising_data_cp ad; memset(&ad, 0, sizeof ad);
    /* flags (LE general discoverable, BR/EDR not supported) + complete list of 128-bit service UUIDs, little-endian */
    static const uint8_t uuid_le[16] = {0x9d,0x0e,0x1f,0x2a,0x3d,0x5c,0x4b,0x9e,0x0c,0x4d,0x2a,0x8f,0x01,0x00,0xe6,0xb1};
    uint8_t* d = ad.data; d[0] = 2; d[1] = 0x01; d[2] = 0x06; d[3] = 17; d[4] = 0x07; memcpy(&d[5], uuid_le, 16); ad.length = 21;
    hci_send_cmd(g_hci, OGF_LE_CTL, OCF_LE_SET_ADVERTISING_DATA, LE_SET_ADVERTISING_DATA_CP_SIZE, &ad);
    le_set_scan_response_data_cp sr; memset(&sr, 0, sizeof sr);   /* complete local name (does not fit beside the UUID) */
    sr.data[0] = 1 + strlen(NAME); sr.data[1] = 0x09; memcpy(&sr.data[2], NAME, strlen(NAME)); sr.length = 2 + strlen(NAME);
    hci_send_cmd(g_hci, OGF_LE_CTL, OCF_LE_SET_SCAN_RESPONSE_DATA, LE_SET_SCAN_RESPONSE_DATA_CP_SIZE, &sr);
  }
  hci_le_set_advertise_enable(g_hci, on ? 0x01 : 0x00, 1000);
  LOG("gatt: advertising %s", on ? "on" : "off");
}
static void on_text_write(struct gatt_db_attribute* a, unsigned id, uint16_t off, const uint8_t* v, size_t len, uint8_t op, struct bt_att* att, void* u) {
  (void)op; (void)att; (void)u; if (g_cb.on_text) g_cb.on_text(off, v, len, g_cb.user); gatt_db_attribute_write_result(a, id, 0);

static void build_db(void) {

  bt_string_to_uuid(&u, TEXT_UUID);

  (void)err; (void)u; LOG("gatt: disconnected");
  if (g_server) { bt_gatt_server_unref(g_server); g_server = NULL; }
  if (g_att) { bt_att_unref(g_att); g_att = NULL; }

  (void)ev; (void)u; struct sockaddr_l2 addr; socklen_t alen = sizeof addr;
  int cfd = accept(fd, (struct sockaddr*)&addr, &alen); if (cfd < 0) return;
  if (g_att) { close(cfd); return; }   /* single central */
  g_att = bt_att_new(cfd, false); bt_att_set_close_on_unref(g_att, true);
  bt_att_register_disconnect(g_att, on_disconnect, NULL, NULL);
  g_server = bt_gatt_server_new(g_db, g_att, 517, 0);
  advertise(0); LOG("gatt: connected");
  if (g_cb.on_connected) g_cb.on_connected(1, g_cb.user);
}

  int fd = socket(PF_BLUETOOTH, SOCK_SEQPACKET, BTPROTO_L2CAP); if (fd < 0) return -1;
  struct sockaddr_l2 a; memset(&a, 0, sizeof a); a.l2_family = AF_BLUETOOTH; a.l2_cid = htobs(ATT_CID);
  bacpy(&a.l2_bdaddr, BDADDR_ANY); a.l2_bdaddr_type = BDADDR_LE_PUBLIC;
  if (bind(fd, (struct sockaddr*)&a, sizeof a) < 0) { close(fd); return -1; }
  struct bt_security sec = { .level = BT_SECURITY_LOW, .key_size = 0 };
  setsockopt(fd, SOL_BLUETOOTH, BT_SECURITY, &sec, sizeof sec);
  if (listen(fd, 1) < 0) { close(fd); return -1; }
  return fd;
}
static void* thread_main(void* arg) {
  (void)arg; mainloop_init(); build_db();
  g_hci = hci_open_dev(0); if (g_hci < 0) { LOG("gatt: hci_open_dev failed"); return NULL; }
  g_listen = listen_att(); if (g_listen < 0) { LOG("gatt: l2cap listen failed: %s", strerror(errno)); return NULL; }
  mainloop_add_fd(g_listen, EPOLLIN, on_accept, NULL, NULL);
  advertise(1); mainloop_run(); return NULL;
}
int kiep_gatt_start(const kiep_gatt_callbacks* cb) { g_cb = *cb; return pthread_create(&g_thread, NULL, thread_main, NULL); }
void kiep_gatt_stop(void) { advertise(0); mainloop_quit(); pthread_join(g_thread, NULL); }
```

```python
#!/usr/bin/env python3
"""Laptop as the keyboard: write KiepDisplay frames over BLE. Same bytes as the Android app."""
import asyncio, sys
from bleak import BleakClient, BleakScanner
SERVICE = "b1e60001-8f2a-4d0c-9e4b-5c3d2a1f0e9d"; TEXT = "b1e60002-8f2a-4d0c-9e4b-5c3d2a1f0e9d"; ATTENTION = "b1e60003-8f2a-4d0c-9e4b-5c3d2a1f0e9d"

def frame(cmd, arg=None):
    if cmd in ("M", "W", "L"): return TEXT, cmd.encode() + (arg or "").encode("utf-8")
    if cmd == "attention": return ATTENTION, bytes([1, int(arg or 1)])
    if cmd == "yes": return ATTENTION, bytes([2, 1])
    if cmd == "no": return ATTENTION, bytes([3, 1])
    raise SystemExit(f"unknown command {cmd}")

async def find():
    dev = await BleakScanner.find_device_by_filter(lambda d, ad: SERVICE in (ad.service_uuids or []) or d.name == "KiepDisplay", timeout=15)
    if not dev: raise SystemExit("KiepDisplay not found (is the heartbeat blinking?)")
    print("found", dev.address); return dev

async def send_all(lines):
    async with BleakClient(await find()) as c:
        for line in lines:
            cmd, _, arg = line.partition(" "); uuid, data = frame(cmd, arg or None)
            await c.write_gatt_char(uuid, data, response=True); print("sent", cmd, len(data), "bytes")

def main():
    if len(sys.argv) < 2: raise SystemExit(__doc__ + "\nusage: send.py M|W|L TEXT | attention [N] | yes | no | shell")
    if sys.argv[1] == "shell":
        print("one frame per line, e.g. `M Hallo`, ctrl-Z/ctrl-D to quit"); lines = [l.rstrip("\n") for l in sys.stdin if l.strip()]
    else: lines = [" ".join(sys.argv[1:])]
    asyncio.run(send_all(lines))
if __name__ == "__main__": main()
```

```cpp
// Frame: FF 55 cmd len payload ck_hi ck_lo ; checksum = 16-bit sum of all bytes before it (big-endian)
#include "Mcu.h"
#include "Log.h"
#include <fcntl.h>
#include <poll.h>
#include <termios.h>
#include <unistd.h>
#include <cstring>

bool Mcu::open() {
  fd_ = ::open("/dev/ttyS1", O_RDWR | O_NOCTTY | O_NONBLOCK); if (fd_ < 0) { KLOGW("mcu: open ttyS1 failed"); return false; }
  termios t{}; tcgetattr(fd_, &t); cfmakeraw(&t); cfsetispeed(&t, B1500000); cfsetospeed(&t, B1500000);
  t.c_cflag |= CLOCAL | CREAD; tcsetattr(fd_, TCSANOW, &t); tcflush(fd_, TCIOFLUSH); return true;
}
bool Mcu::transact(uint8_t cmd, const uint8_t* payload, int plen, std::vector<uint8_t>& resp) {
  if (fd_ < 0) return false;
  uint8_t tx[40] = {0xFF, 0x55, cmd, (uint8_t)plen}; memcpy(tx + 4, payload, plen);
  uint16_t ck = 0; for (int i = 0; i < 4 + plen; i++) ck += tx[i]; tx[4 + plen] = ck >> 8; tx[5 + plen] = ck & 0xFF;
  std::lock_guard<std::mutex> l(mu_); tcflush(fd_, TCIFLUSH); ::write(fd_, tx, 6 + plen);
  uint8_t rx[64]; int n = 0; pollfd p{fd_, POLLIN, 0};
  for (int tries = 0; tries < 20 && n < 6; tries++) { if (poll(&p, 1, 50) > 0) { int r = ::read(fd_, rx + n, sizeof rx - n); if (r > 0) n += r; } }
  while (n >= 6) {
    if (rx[0] != 0xFF || rx[1] != 0x55) { memmove(rx, rx + 1, --n); continue; }
    int len = rx[3], total = len + 6; if (n < total) { if (poll(&p, 1, 50) > 0) { int r = ::read(fd_, rx + n, sizeof rx - n); if (r > 0) n += r; continue; } return false; }
    uint16_t sum = 0; for (int i = 0; i < total - 2; i++) sum += rx[i];
    if (sum != ((rx[total - 2] << 8) | rx[total - 1])) return false;
    if (rx[2] != cmd) { memmove(rx, rx + total, n -= total); continue; }   // unsolicited report (mic, keys): skip
    resp.assign(rx + 4, rx + 4 + len); return true;
  }
  return false;
}

}
```

```cpp
#endif

#endif
    busy_ = false;
  }).detach();
}
}
```

```python
#!/usr/bin/env python3
"""Deploy, drive the TC002 from the laptop over BLE, capture frames, assert. Reusable for every future feature."""
import argparse, asyncio, json, pathlib, subprocess, sys, time
from PIL import Image
sys.path.insert(0, str(pathlib.Path(__file__).parent))
import screen, send
ROOT = pathlib.Path(__file__).resolve().parents[1]; GOLD = ROOT / "tests/golden"; W, H = 52, 16

def adb(cmd): return subprocess.run(["adb", "shell", cmd], check=True, capture_output=True, text=True).stdout
def restart_app(): adb("setprop ctl.stop zkswe; sleep 1; setprop ctl.start zkswe"); time.sleep(6)
def mask(rgb): return bytes(1 if (x != 51 or y != 0) and max(rgb[(y * W + x) * 3:(y * W + x) * 3 + 3]) > 0 else 0 for y in range(H) for x in range(W))
def lit_cols(rgb): m = mask(rgb); cols = [x for x in range(W) if any(m[y * W + x] for y in range(H))]; return (cols[0], cols[-1]) if cols else (-1, -1)
def color(rgb):
    m = mask(rgb); lit = [rgb[i * 3:i * 3 + 3] for i in range(W * H) if m[i]]
    if len(lit) < W * H // 2: return "dark" if len(lit) == 0 else "text"
    r, g, b = (sum(p[c] for p in lit) // len(lit) for c in range(3))
    return "white" if min(r, g, b) > 100 else "green" if g > r and g > b else "red" if r > g and r > b else "other"
def golden_check(name, rgb, update):
    img = Image.frombytes("L", (W, H), bytes(255 * v for v in mask(rgb))); path = GOLD / f"{name}.png"
    if update or not path.exists(): GOLD.mkdir(exist_ok=True); img.save(path); return True, "golden written"
    return list(img.getdata()) == list(Image.open(path).convert("L").getdata()), "golden mismatch"

async def run_fixture(fx, update):
    if fx.get("idle_ms"): adb(f"mkdir -p /tmp/kiep; echo {fx['idle_ms']} > /tmp/kiep/idle_ms"); restart_app()
    lines = [("Lange zin " * 30) if "<300 chars" in l else l.replace("\\n", "\n") for l in fx["send"]]
    dev = await send.find()
    async with send.BleakClient(dev) as c:
        for l in lines:
            cmd, _, arg = l.partition(" "); uuid, data = send.frame(cmd, arg or None)
            await c.write_gatt_char(uuid, data, response=True); await asyncio.sleep(fx.get("gap_ms", 50) / 1000)
        if fx.get("disconnect"): pass   # leaving the block disconnects
        else: await asyncio.sleep(fx["wait_ms"] / 1000); frames = screen.pull(None)
    if fx.get("disconnect"): await asyncio.sleep(fx["wait_ms"] / 1000); frames = screen.pull(None)
    if fx.get("idle_ms"): adb("rm -f /tmp/kiep/idle_ms"); restart_app()
    ts, rgb = frames[-1]; last_s = [f for f in frames if f[0] >= ts - 1000]; fails = []
    e = fx["expect"]; lo, hi = lit_cols(rgb)
    if "lit_cols_min" in e and not (e["lit_cols_min"][0] <= lo <= e["lit_cols_min"][1]): fails.append(f"lit_cols_min {lo}")
    if "lit_cols_max" in e and not (e["lit_cols_max"][0] <= hi <= e["lit_cols_max"][1]): fails.append(f"lit_cols_max {hi}")
    if "color" in e and color(rgb) != e["color"]: fails.append(f"color {color(rgb)}")
    if "motion" in e:
        distinct = len({f[1] for f in last_s}); moving = distinct >= 5
        if moving != e["motion"]: fails.append(f"motion distinct={distinct}")
    if "interval" in e and len(last_s) > 2:
        d = [last_s[i + 1][0] - last_s[i][0] for i in range(len(last_s) - 1)]; mean = sum(d) / len(d)
        if not (e["interval"][0] <= mean <= e["interval"][1]) or max(d) > e["interval"][2]: fails.append(f"interval mean={mean:.1f} max={max(d)}")
    if e.get("golden"):
        ok, msg = golden_check(fx["name"], rgb, update)
        if not ok: fails.append(msg); screen.png(rgb).save(ROOT / f"out/fail_{fx['name']}.png")
    return fails

def main():
    ap = argparse.ArgumentParser(); ap.add_argument("--no-deploy", action="store_true"); ap.add_argument("--update", action="store_true"); ap.add_argument("--only")
    a = ap.parse_args()
    if not a.no_deploy: subprocess.run([sys.executable, str(ROOT / "tools/deploy.py")], check=True); time.sleep(6)
    fixtures = json.loads((ROOT / "tests/fixtures.json").read_text()); failed = 0
    for fx in fixtures:
        if a.only and fx["name"] != a.only: continue
        fails = asyncio.run(run_fixture(fx, a.update)); failed += bool(fails)
        print(f"{'PASS' if not fails else 'FAIL'} {fx['name']}" + (f": {', '.join(fails)}" if fails else ""))
    print(f"{len(fixtures) - failed}/{len(fixtures)} passed"); sys.exit(1 if failed else 0)
if __name__ == "__main__": main()
```

```python
def pack_update_img(sqsh: bytes, template: bytes | None) -> bytes:
    img = sqsh + b"\0" * (-len(sqsh) % 4096)
    md5 = hashlib.md5(img).digest()
    hdr = bytearray(template[:0x24C]) if template else bytearray(0x24C)
    if not template:
        hdr[0:16] = b"ZKSWEV1.0-180127"; hdr[0x10] = 0x30; hdr[0x11] = 1; hdr[0x12] = 0x30; hdr[0x13] = 0x23
        struct.pack_into("<I", hdr, 0x30, 0x20C); hdr[0x34] = 0x02; struct.pack_into("<I", hdr, 0x35, 0xAA550606); hdr[0x39] = 0
    e = 0x14; hdr[e] = 3; hdr[e + 1:e + 4] = bytes.fromhex("10606c")
    struct.pack_into("<II", hdr, e + 4, 0x23C, len(img)); hdr[e + 0x0C:e + 0x1C] = img[:16]
    hdr[0x23C:0x24C] = md5
    struct.pack_into("<I", hdr, 0x238, zlib.crc32(bytes(hdr[:0x238])) & 0xFFFFFFFF)
    return bytes(hdr) + img[16:]

def unpack_update_img(data: bytes) -> bytes:
    off, size = struct.unpack_from("<II", data, 0x18); first16 = data[0x20:0x30]
    return first16 + data[off + 16: off + size]
```
Test (`tests/test_update_img.py`, runs in the container, needs a vendor image from `backup`): `assert pack_update_img(unpack_update_img(v), v) == v` — byte-identical round trip proves the packer before anything is flashed. Also `inspect` prints the fields.
