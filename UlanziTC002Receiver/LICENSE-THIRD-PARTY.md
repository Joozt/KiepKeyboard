repository `UlanziTechnology/Ulanzi-U-Clock-TC002` at commit `677a3aa89784bcb0b3e5ffa6db954efa0ce880de`

and Google Inc., licensed under the GNU Lesser General Public License 2.1 or later. Source:

Nothing else from that demo repository (GPL-3.0) is used: the receiver's MCU, panel, input,
Bluetooth bring-up and GATT code are written from documented protocol facts.

The Z21 SDK headers and link stubs (`easyui`, `log`, `base-utility`, `audio-utility`, `ffmpeg`,
`z`, `mi_*`, `cam_os_wrapper`, `base-json`) are fetched at build time from `package.flythings.cn`
